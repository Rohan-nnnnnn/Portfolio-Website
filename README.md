A personal portfolio website showcasing my work, projects, technical skills, and professional background in **AI Automation and AI Engineering**.

## Overview

This portfolio presents my journey as an Electronics and Telecommunication Engineering student focused on building intelligent systems, AI-powered workflows, and practical automation solutions.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Rohan-nnnnnn/Portfolio-Website.git
```

Navigate to the project directory:

```bash
cd Portfolio-Website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.
